# Invalid compute plugin call or declaration

A compute plugin is missing, or a call does not satisfy its argument contract.
Load the plugin with `moc --plugin <package-directory>` before compiling.

Type-specialized intrinsics infer their argument types at each call. For
example, `Prim.to_candid_canonical(value)` requires a shared type, as does
`to_candid`. It cannot encode a local function or mutable array. Do not supply
explicit type arguments to an intrinsic; annotate the value instead when a
particular argument type is required.

Intrinsics retain their identity through inferred aliases, but cannot be
annotated as ordinary Motoko functions. A fixed-signature plugin function such
as `Prim.sha256 : Blob -> Blob` is an ordinary function and can be passed as a
callback.
